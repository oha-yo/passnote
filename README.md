# passnote（接続情報）

ブラウザで開く、自分用の**接続情報のメモ**です。Web（http）・SSH・データベース（PostgreSQL）の接続先・ユーザー・パスワードをまとめて控えておけます。HTML ファイル 1 つで動きます（インストールもサーバーも不要）。

- 画面上のパスワードは `••••••••` で隠れていて、コピーのボタンで本物がクリップボードに入ります。
- 中身は**全部**（名前・接続先・ユーザー・メモも）マスターパスワードで暗号化して保存します（AES-GCM 256bit、鍵は PBKDF2-SHA256 60 万回）。画面で隠すのはパスワードだけです。
- 外部のライブラリやネットへの通信は使いません。
- 画面に出す名前「接続情報」は仮称です（`passnote.html` の `APP_NAME` で変えられます）。もとは「パスワード帳」でした。

## 使い方
1. `passnote.html` を Chrome か Edge で開く（ダブルクリック）。
2. 初回はマスターパスワードを決める。**忘れると中身は二度と取り出せません。**
3. 「＋ 追加」で、まず**種類**（Web（http）・SSH・データベース（PostgreSQL））を選んで登録する。

| 種類 | 入れられる項目 |
|---|---|
| Web（http） | 名前・URL・ユーザー名・パスワード・分類・大切さ・メモ |
| SSH | 名前・ホスト・ポート（初期値 22）・ユーザー名・パスワード・分類・大切さ・メモ |
| データベース（PostgreSQL） | 名前・ホスト・ポート（初期値 5432）・データベース名・ユーザー名・パスワード・分類・大切さ・メモ |

一覧では1件を1行に、種類のアイコン・名前・接続先・ユーザー・パスワードの順に並べます（狭い画面では折り返します）。検索欄の下のボタン（すべて・Web（http）・SSH・データベース（PostgreSQL））で、**種類ごとに絞り込めます**（検索と組み合わせられます）。

**重要のスイッチ**：「すべて」の左のスイッチが OFF（ふだん）のときは、大切さが「重要」のものを一覧に出しません。ON にすると「重要」のものだけを出します。検索や種類の絞り込みは、どちらのときも使えます。ロックすると OFF に戻ります。

**並べ替え**：行の左端のつまみ（⋮⋮）を押したまま上下に動かすと、好きな順に並べ替えられます（離したところに移ります）。順番は保存されます。一度も並べ替えていないうちは、分類 → 名前の順に並びます。

| 操作 | ボタン |
|---|---|
| 編集 | ✎（行の右端） |
| パスワードを表示・隠す | 👁（10 秒で自動的に隠れる） |
| コピー | ⧉（コピーできると 1.5 秒だけ ✓ になる） |
| 接続のコマンドをコピー | 接続先の横の ⧉（SSH は `ssh user@host -p ポート`、データベースは `psql -h host -p ポート -U user -d データベース名`。パスワードは入れない） |

- Web（http）の名前は URL へのリンクになり、マウスを乗せると URL が出ます。
- コピーしたパスワードは 30 秒後にクリップボードから消します（画面を開いているとき）。
- 5 分間操作がないと自動でロックします。

## マスターパスワードを忘れたとき
- 中身はマスターパスワードで暗号化しているので、**パスワードがわからないと取り出す方法はありません。**
- ロック画面の「マスターパスワードを忘れた場合」から**初期化**できます。確認のため「初期化する」と入力すると、このブラウザのデータを消して、最初の画面（新しいマスターパスワードを決める）に戻ります。
- 消す前に、今の中身を暗号化したまま `pass-note-backup-before-reset-日付.json` としてダウンロードします。あとでマスターパスワードを思い出したら、「バックアップから復元」で元に戻せます。

## データの保存場所
- ブラウザの **localStorage** に、キー `pass-note-vault-v1` で保存します。中身は暗号化されています（名前を変えても、キーは互換のためそのまま）。
- 「パスワード帳」のころに登録したものは、Web（http）として表示します。
- HTML ファイルには書き込みません。HTML を別の場所に移しても、同じブラウザで開けば同じデータが見えます。
- 実際のファイルは、ブラウザが管理するフォルダの中にあります。
  - Chrome: `%LOCALAPPDATA%\Google\Chrome\User Data\Default\Local Storage\leveldb\`
  - Edge: `%LOCALAPPDATA%\Microsoft\Edge\User Data\Default\Local Storage\leveldb\`
- **ブラウザごと・プロフィールごとに別々**です。いつも同じブラウザで開いてください。
- ブラウザの「閲覧データの削除」（Cookie と他のサイトデータ）で消える可能性があります。

## バックアップ
- 「その他 → バックアップを保存」で、暗号化したファイル（`pass-note-backup-日付.json`）をダウンロードします。
- 別の PC やブラウザでは「バックアップから復元」を使います。作ったときのマスターパスワードが必要です。
- **バックアップのファイルは、このプロジェクトのフォルダに置かないでください**（Git の管理に入らないよう `.gitignore` でも除外しています）。
